## 07. Architecture & Repository Structure

Built with **React 19**, **TypeScript ~6.0**, **Vite 8**, **Tailwind CSS v4**, **Framer Motion 13**, and **Lucide React**, with route-level `React.lazy` code-splitting and adaptive Desktop/Mobile GPU canvas rendering.

```text
mostafa-portfolio/
├── index.html                              # SEO/OG metadata, Sora + Manrope + JetBrains Mono + Cairo fonts
├── package.json                            # React 19, Vite 8, Tailwind CSS v4, Framer Motion, TypeScript
├── vite.config.ts                          # Vite 8 build & bundling configuration
├── public/
│   ├── Mostafa_Elshorbagy_CV.pdf           # Official CV PDF (served at /Mostafa_Elshorbagy_CV.pdf)
│   ├── cv/Mostafa_Elshorbagy_CV.pdf        # Secondary CV endpoint (/cv/Mostafa_Elshorbagy_CV.pdf)
│   ├── favicon.svg                         # Custom M! brand mark favicon
│   ├── assets/
│   │   ├── brands/                         # 18 high-resolution transparent PNG/WEBP/SVG brand marks
│   │   └── tech/                           # 35 authentic official Devicon/vector technology SVGs
│   ├── images/
│   │   ├── photo.jpg                       # Personal studio portrait used in Hero & OpenGraph
│   │   ├── step-forward-award.jpg          # 1st Place Step Forward Business Conference 2025 trophy
│   │   ├── egyptian-airports-cert.jpg      # Egyptian Airports Company ICT certificate
│   │   ├── engaz-ai-cert.jpg               # ENGAZ AI internship certificate
│   │   ├── tamooh-cert.jpg                 # TamooH Academy leadership certificate
│   │   └── previews/                       # 19 real 1280x800 live project preview screenshots
│   └── video/
│       └── logo-preloader.mp4              # Desktop-only M! intro accent video
└── src/
    ├── main.tsx                            # Application entry point
    ├── App.tsx                             # Root layout with ErrorBoundary & React.lazy code-splitting
    ├── index.css                           # Design tokens (Dark/Light themes), marquee animations & utilities
    ├── data/
    │   └── portfolio.ts                    # Single source of truth: identity, 6 pillars, 66 skills, 19 brands, 21 projects
    └── components/
        ├── Navigation.tsx                  # Floating header, sliding active pill, social links, CV & theme switch
        ├── SystemIntro.tsx                 # Fast non-blocking intro with instant Skip Intro & session memory
        ├── SectionBackground.tsx           # 7-section art-directed canvas background engine (adaptive mobile static mode)
        ├── HeroSection.tsx                 # 3-column editorial Hero, View/Download CV CTAs & dual kinetic marquees
        ├── AboutSection.tsx                # 2-column editorial bio, award photo, CV bar & embedded Skills matrix
        ├── InteractiveSkillsSection.tsx    # 9-category 3D-inspired interactive technology & capabilities showcase
        ├── SixPillarsEcosystem.tsx         # Interactive 3D Neural Ecosystem + Chemistry Lab starfield canvas
        ├── ProjectGallery.tsx              # Filterable visual showcase of 21 projects with live website previews
        ├── ProjectModal.tsx                # Detailed case-study modal with live deployment links
        ├── ClientsSection.tsx              # Dual counter-flowing brand logo marquees & relationship directory
        ├── Achievements.tsx                # Featured 1st Place Save Money award & verified certificates strip
        ├── OrganizationsSection.tsx        # Professional Journey across ProMedia, ProTech, Life Makers, Save Money & CIC
        ├── Contact.tsx                     # Direct inquiry draft form, email copy & verified social network cards
        ├── Footer.tsx                      # Closing horizon banner, CV actions & quick navigation
        └── ErrorBoundary.tsx               # Graceful runtime error recovery boundary
```

## 08. Local Development & Production Build

```bash
# 1. Install dependencies
npm install

# 2. Start local development server (http://localhost:5173/)
npm run dev

# 3. Run type-checking and production build (outputs to dist/)
npm run build

# 4. Preview the production build locally
npm run preview
```
